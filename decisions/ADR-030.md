# ADR-030 — Model gateway selected: LiteLLM (ADR-027 fallback branch), under ADR-017 controls
**2026-07-12 · Accepted** — resolves the Phase 2 gateway choice opened by ADR-027; records the Bifrost evaluation outcome. Supersedes ADR-027's *preference* for Bifrost on the strength of an empirical test ADR-027 explicitly gated on.

**Context.** ADR-027 fixed the evaluation order: **Bifrost preferred if it passes the role contract → else LiteLLM under ADR-017 controls → else a superior alternative**, and pinned the Bifrost choice to one condition: *"the one thing to verify before committing: Bifrost's per-request `think` passthrough to Ollama… do a smoke test; if it fails or is fiddly, fall back to LiteLLM."* The full evaluation is in [reviews/2026-07-11-gateway-evaluation.md](../reviews/2026-07-11-gateway-evaluation.md).

Bifrost was installed alongside the working system (localhost:4000, Ollama backend, config-only mode) on 2026-07-11/12 and smoke-tested:
- **Basic routing passed** — an OpenAI `/v1/chat/completions` request through Bifrost returned a correct completion from the local Ollama (role-contract criteria 1–7 confirmed empirically).
- **Thinking control failed the gate.** The router's thinking policy (ADR-T3B) requires a genuine per-request *think off* for snappy casual/chat turns. Through Bifrost: (a) Ollama-native `think:false` returned **empty content** with 4059 tokens consumed by hidden reasoning (broken UX); (b) OpenAI-standard `reasoning_effort` was passed through and *scaled* reasoning (minimal→1784 tokens, high→4075) but **never disabled it** — "minimal" still spent ~1784 reasoning tokens on "what is 15% of 80?". Two independent control paths, neither yielding a clean thinking-off.

**Decision.** Adopt **LiteLLM** (proxy mode) as the model gateway, per ADR-027's pre-ratified fallback. LiteLLM has a first-class `reasoning_effort` → Ollama `think` mapping (minimal/none/disable → `think:false`), which preserves the router's thinking policy exactly — the single axis on which it is cleaner than Bifrost, and the one this system depends on.

LiteLLM is adopted **only under ADR-017's mandatory controls** (its 2026 security record demands them): pin to a vetted stable (latest 1.91.x at adoption), verify package integrity at install, master key enabled, bound to 127.0.0.1 only, security-advisory check in the quarterly checkup, out-of-cycle patching on any pre-auth/RCE-class advisory. Bifrost remains the **named successor** (Law 4) — if a future LiteLLM advisory forces a swap, or if Bifrost gains first-class Ollama `think` mapping, revisit.

**Consequences.** The router's per-capability thinking control survives the gateway cutover, so JARVIS stays snappy on casual turns and deliberate on consequential ones. Cost accepted, eyes open: LiteLLM carries the heaviest security record of the candidates (CVEs incl. CISA-KEV, a 2026 PyPI supply-chain incident) — mitigated, not eliminated, by ADR-017's pinning/verification/localhost-only posture and the no-public-exposure architecture (ADR-026). The Bifrost trial config is retained under `config\gateway\` as evaluation evidence (inactive).

**Alternatives considered.** (1) *Bifrost with `reasoning_effort` scaling, accepting no clean think-off* — rejected: casual/chat on the 9B would always burn ~1.8k hidden reasoning tokens, a real latency regression from the Phase-1 direct path for the operator's most-used interaction. (2) *Bifrost with native `think` passthrough* — rejected: empirically broken (empty content). (3) *No gateway in front of local Ollama (keep the router native)* — rejected: ADR-002/027 mandate the gateway seam; skipping it needs a superseding ADR, and the seam's value (provider-agnostic routing, failover, one place to re-add cloud) is the point of Phase 2. (4) *The ~50-line own proxy (ADR-002 floor)* — deferred: LiteLLM meets the contract now; the own-proxy remains the last-resort filler if LiteLLM's posture becomes untenable.

**Future review criteria.** Reopen if: (a) a LiteLLM pre-auth/RCE advisory or supply-chain event lands — execute the Bifrost/own-proxy swap per MAINTENANCE §2 rather than absorbing another strike; (b) Bifrost ships a documented first-class Ollama `think` mapping — re-evaluate (its clean-record/small-footprint advantages still stand); (c) the local model family changes such that thinking-off is no longer needed — the gating criterion relaxes; (d) the LiteLLM smoke test (next step) does **not** cleanly map `reasoning_effort:minimal`→`think:false` — then neither gateway supports the requirement and this becomes an escalation, not a silent choice.
