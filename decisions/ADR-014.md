# ADR-014 — Substrate: Windows 11 plus uv-managed Python; amends ADR-006
**2026-07-10 · Accepted** — ratifies [ARCHITECTURE-V2](../ARCHITECTURE-V2.md) §8/§12.

**Context.** The red-team review ([C1, I1](../reviews/2026-07-09-red-team-review.md)) found the system founded on an OS already past end-of-support (Windows 10 Pro N 19045, EOL October 2025 — and still running on the target machine as of 2026-07-10), with the N edition missing the Media Feature Pack the Phase 4 voice stack may need. Separately, ADR-006's "no Docker, no WSL, native installs only" contradicted the component registry: LiteLLM is a Python package, Open WebUI is Docker-first, Postiz Docker-only — and no document installed or pinned Python. Since then, Windows 11 has also become the *positive* choice: it ships native MCP support and Agent Workspace sandboxing (the substrate primitive ADR-020 adopts).

**Decision.**

1. **Windows 11 migration is a Phase 0 exit gate.** The hardware (RTX 4070 Ti, 31 GB RAM) supports it. Nothing past Phase 0 begins on Windows 10. An OS-EOL check joins the quarterly checkup permanently. The Media Feature Pack is installed before Phase 4.
2. **uv (Astral) is the managed Python runtime substrate.** Python-based components (LiteLLM, faster-whisper, and peers) run under pinned uv environments. ADR-006 is amended: native-Python-via-uv is permitted; Docker and WSL still require a superseding ADR.
3. Docker-only components are thereby demoted where alternatives exist: Postiz becomes "optional, deferred," with per-platform MCP servers as the default social path.

**Consequences.** The foundation stops being condemned, and the Phase 4 audio risk is closed before it is hit. uv gives reproducible, pinned Python environments a non-programmer never has to manage by hand. Cost: uv is pre-1.0 (API churn risk in install scripts — pin its version too, in VERSIONS.md per ADR-016's gate list), and the Windows 11 migration is a real half-day of operator work that must happen before anything fun does.

**Alternatives considered.** (1) *Stay on Windows 10 with ESU* — rejected: paying to defer the same migration on a condemned foundation, and it forfeits native MCP and Agent Workspace. (2) *WSL as the Python substrate* — rejected: a second operating system's worth of maintenance for a non-programmer (ADR-006's original reasoning stands). (3) *System Python + venvs* — rejected: exactly the unmanaged state I1 flagged; uv pins interpreter and packages in one tool. (4) *Conda/miniforge* — rejected: heavier, slower, and solving problems (native scientific stacks) this system doesn't have.

**Future review criteria.** Reopen if: (a) uv reaches 1.0 (re-pin and relax churn caution) or stalls (successor: pip + venv with a lockfile discipline, recorded in COMPONENTS.md); (b) a load-bearing component becomes Linux-only with no Windows-native peer — that is the superseding-ADR trigger ADR-006 always specified; (c) Windows 11 approaches its own EOL — the quarterly OS check exists precisely so this ADR's successor is written years early, not months late.
