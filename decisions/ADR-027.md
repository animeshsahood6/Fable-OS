# ADR-027 — Gateway strategy: the seam from Day 1, the software from Phase 2
**2026-07-11 · Accepted** — records the operator's 2026-07-11 directive; supersedes-in-part ADR-017 (evaluation order) and defines the Phase 1 interim for ADR-002/ADR-024.

**Context.** ADR-002's load-bearing guarantee is the **seam**: every consumer speaks one OpenAI-compatible dialect to a base URL read from `config\models.yaml`; no component embeds a provider SDK or hardcoded model name. The proxy software was always a role-filler, not the guarantee. Deferring gateway software removes one install, one security-critical dependency (ADR-017's 2026 CVE record), and one moving part from the critical path to a working system — provided the seam itself is binding from the first line of configuration. Ollama natively serves an OpenAI-compatible `/v1` endpoint, making the local half of the seam free.

**Decision.**

1. **The seam is binding from Day 1.** `config\models.yaml` is the single registry of task routes (`reasoning`, `fast`, `embedding`, each with a local fallback and an offline-capable flag per ADR-024 item 4). Every consumer resolves models only through it. No provider SDK, key, or model name may appear anywhere else.
2. **Phase 1 runs with direct adapters only — no gateway software.** Exactly two backends: (a) **Ollama's native `/v1` endpoint** for local models; (b) **one frontier model via a direct adapter** — a single, confined integration point behind the seam, implemented once, marked for deletion. Nothing else may call the frontier provider.
3. **Phase 2 installs the gateway and deletes the direct adapter.** Evaluation order: **Bifrost** (preferred if it passes the role contract of ARCHITECTURE.md §2), then **LiteLLM** (under ADR-017's mandatory controls: pin, hash-verify, master key, 127.0.0.1+tailnet-only binding), then any objectively superior alternative found at evaluation time. The winner is recorded in COMPONENTS.md with a named successor (Law 4); the cutover is a base-URL edit in `models.yaml` — if it is more than that, the seam was violated and that is the bug.
4. **Accepted, dated interim gaps (Phase 1 only):** ADR-024's *automatic* failover does not exist yet — fallback is a manual `models.yaml` edit, documented as a one-paste operator action; cost governance (red-team I4) is enforced by **provider-console spend caps** set the same day the frontier key is created. Both gaps close at Phase 2 gateway cutover, which is the trigger, not a date.
5. **The gateway remains replaceable forever:** consumers know only the seam; the ~50-line own-proxy floor (ADR-002) remains the last-resort filler.

**Consequences.** The first working Jarvis arrives one install sooner and with a smaller attack surface; ADR-002's guarantee survives untouched because it was always the dialect + the one config file, not the proxy. Cost: for the life of Phase 1, a frontier-provider outage requires a manual (though trivial) fallback edit, and one piece of throwaway code (the direct adapter) exists solely to be deleted — its deletion is a Phase 2 Definition-of-Done item, preventing the temporary from becoming permanent.

**Alternatives considered.** (1) *Install LiteLLM in Phase 1 as originally planned* — rejected: adds a security-critical service (ADR-017's CVE record) to the least-mature moment of the system for zero Phase 1 capability gain over direct endpoints. (2) *No frontier model in Phase 1 (local only)* — rejected: Law 6 makes offline the baseline, not the ceiling; the frontier model is most of the assistant's day-one usefulness. (3) *Two direct adapters (two frontier providers) for redundancy* — rejected: doubles the throwaway code and halves the pressure to reach Phase 2, where redundancy is done properly (ADR-024 chains). (4) *Skipping the gateway permanently (adapters forever)* — rejected: N providers × M consumers without a seam-enforcing component is exactly the point-to-point wiring ARCHITECTURE.md §6 refuses.

**Future review criteria.** Reopen if: (a) at Phase 2 evaluation, Bifrost fails the role contract *and* LiteLLM's security posture has not improved — the ~50-line own proxy is then evaluated seriously, not as rhetoric; (b) the direct adapter survives past Phase 2's Definition of Done — that is a failed gate, treated as an incident; (c) a second consumer needs the frontier model before Phase 2 begins — that is the signal Phase 2 is late, not a license for a second adapter; (d) an OpenAI-compatible-dialect successor standard emerges — the seam's dialect is re-pinned by new ADR, wrappers regenerate (ADR-001 logic).
